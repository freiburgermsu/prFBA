- Anchor = reps[0] of predictions.json (prFBA's own anchor: highest identity-decayed representativeness, then genome id). The clade includes the anchor and any other rep in it.
- Clades come from panel_eligible lineage (not the hits' lineage). Labels starting 'unclassified_' (panel placeholders, e.g. 'unclassified_family:Lactobacillaceae' as a genus) are treated as 'no clade at this rank' and back off, like a clade with < 3 reference genomes. The back-off chain stops at order; with no admissible clade the alpha term is dropped (E2 = k/n, E3 = E1 for that cell).
- E4 isotonic is fitted on binned universe points (exact 0, 4,000 uniform bins, exact 1; x = bin mean, weight = points), with sklearn PAVA, and applied to the outer fold's exact q by the fitted piecewise-linear map. The map for outer fold f uses only the other four folds and the variant selected for f.
- Stage O's single isotonic map (if an E4 estimator wins) is fitted on all five folds with the carried-forward configuration; it is therefore in-sample for the 360 benchmark amplicons (0.6% of cells); the nested-CV numbers above are the honest ones.
- Winner rule (the design names none): among estimators whose universe-Brier and union-Brier contrasts vs E0 both have group CIs below 0, the lowest nested-CV universe log-loss (the tuning criterion). Carried-forward tie-breaks beyond 'smaller K, larger tau': genome before species, genus before family, smaller alpha.
- AUROC point estimates are exact (ties 1/2); bootstrap replicates use 1,001-bin histograms (scores.json gives the binned point estimate too).
- Universe ECE uses calibrate's decile bins with exact 0 and exact 1 as their own bins (for unrecalibrated q this is calibrate's 'ece_decile_universe'). ECE is a sum of absolute bin errors and is biased upward under resampling, so for a well-calibrated (E4) estimator its percentile interval can lie above the point estimate; read it as a descriptive number, not a contrast.
- Cells whose anchor has no admissible clade up to order (placeholder order label or an order with < 3 fold-reference genomes; counts in the diagnostics) keep the alpha term out: E2 = k/n and E3 = E1 there. The schema's clade ranks stop at order, so the back-off was not extended to class.
- Density sensitivity: the carried-forward configurations at d050/d025 without re-tuning (E4 refitted out of fold within the density); the clade prior uses that density's fold reference.

## Caveats

- Post hoc: declared after the calibration study's exploratory top-k analysis had been seen. Nested selection protects the reported numbers from the tuning, not from the choice of the grids, which was informed by that analysis.
- Transfer: the benchmark reference is ~6,800 species-dereplicated genomes per fold. Production searches ~315,000 genomes, where the first 100 hits of a well-sequenced species can be one species and identity weighting collapses onto the tie set; the species-dedup variant cannot speak to this here (the panel holds one genome per species), only the density sensitivity can, and only partially.
- Genus-blocked folds: every number is cross-genus transfer (the source's genus is never in the reference); the clade prior is the nearest available clade, never the source's.
- Support expansion: E1-E4 give non-zero q outside the union (and E4 maps q = 0 to the base rate). Universe metrics include it; Stage O does not use it (union support only).
